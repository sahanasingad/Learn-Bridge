# Setup & Run Instructions

← [Back to README](../README.md)

## Project Overview

Learn Bridge is a browser-based student and mentor learning portal covering:

- Music
- Public Speaking & Communication
- Python Programming

The current version runs primarily in the browser and stores user progress and recordings locally.

---

## Prerequisites

| Tool | Version | Purpose |
|---|---|---|
| Node.js | 18+ recommended | Runs the local development server |
| Modern Browser | Chrome or Edge recommended | Runs the Learn Bridge application |
| Git | Any recent version | Clone and manage the project |

No database server, Docker, or separate backend server is required for the current version.
